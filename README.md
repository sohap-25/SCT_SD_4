# E-Commerce Product Scraper (Java)

## Overview
This project is a Java-based E-Commerce Product Scraper that extracts:

- Product Name
- Product Price
- Product Rating

from an online e-commerce website and stores the extracted data into a structured CSV file.

The project also includes a simple GUI using Java Swing.

---

## Features
- Extracts live product data
- Saves data into CSV format
- User-friendly GUI
- Uses Java networking and file handling
- No external libraries required

---

## Technologies Used
- Java
- Java Swing
- HttpURLConnection
- BufferedReader
- Regular Expressions
- FileWriter

---

## Website Used
This project extracts data from:

https://books.toscrape.com/

This website is specially designed for practicing web scraping safely.
